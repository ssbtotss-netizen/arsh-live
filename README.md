# B6O6 Streaming

منصة عربية لأدوات البث المباشر على TikTok LIVE (Overlays لـ OBS، قوائم الداعمين، تنبيهات المتابعين، عداد المتابعين، السبثون، البوتات، الشات الموحد، إحصائيات نهاية البث، الاشتراكات).

- الخادم وتطبيق Next.js: `arsh-live/`
- لوحة التحكم المختبرة (تُبنى إلى `arsh-live/public/b6o6-dashboard.js`): `demo/` عبر `python3 demo/build.py`
- النشر على Render: `render.yaml` (خادم Node + PostgreSQL)
- سجل التقدم: `B6O6_PROGRESS.md`

> النسخة السابقة من هذا المستودع (موقع «عرش اللايف») محفوظة في سجل Git قبل هذا الالتزام.
